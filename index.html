Bienvenidos


Usar flex-direction: row permite mantener un diseño horizontal, haciendo que los elementos se coloquen uno al lado del otro. Esto es útil en pantallas grandes como computadoras, barras de navegación, secciones principales de páginas web y galerías, ya que permite aprovechar mejor el espacio y mostrar el contenido de forma más ordenada y visualmente atractiva.


Actividad Asignada


Usar flex-direction: column permite cambiar un diseño horizontal a vertical, colocando los elementos uno debajo del otro. Esto es útil en celulares, diseños responsive y menús móviles, porque mejora la organización y la adaptación del contenido.
